## 用户需求

在现有 trimmed-mean 估值因子合成基础上,新增一项独立的「行业内 PB 相对」统计分量并参与最终合成:

- 当前最终合成公式为 `valuation = (mult_score * Wm + dv_ttm_score * 4) / (Wm + 4)`。
- 新增分量:按 `pb` 进行行业内 `groupby`,组内 `rank_to_score` 后 `×-1`(反向),权重为 2。
- 该分量与 `mult_score` 中「全市场低 PB→高分」的价值维度方向相反,作为「行业内高 PB→高分」的相对溢价/成长维度独立计入。

## 补充口径(已声明假设)

- 新增分量沿用此前 `pb` 的原始写法:对 `pb_inv`(1/pb)做行业内 `rank_to_score` 再 `×-1`,即**行业内高 PB→高分**。若实际需「行业内低 PB→高分」可在确认时调整。
- 仅改动 `src/factor.py` 的 `cal_valuation_factor`,不改动表结构、`FACTOR_REGISTRY` 与落库逻辑(`valuation` 仍为 `[-100,100]` int)。

## 核心特性

- 新增 `pb_ind_score`:行业内相对 PB 排名(反向)分量,权重 2。
- 最终合成扩展为 `(mult_score*Wm + dv_ttm_score*4 + pb_ind_score*2) / (Wm + 4*(dv有效) + 2*(pb_ind有效))`,分母按缺失自适应。
- 全部有效时总权重 = 6(mult 块) + 4(dv) + 2(pb_ind) = 12;`pb` 以「全市场价值」与「行业内相对溢价」两种身份参与,属用户明确要求。

## 技术栈

- 语言/运行时:Python 3 + pandas + numpy(与现有 `factor.py` 一致)。
- 复用既有工具:`robust_z_to_score`、`rank_to_score`(均已导入)、`get_daily_basic_by_trade_date`、`upsert_stock_factor`。
- 无需新增依赖、无需改表结构(`StockFactor.valuation` 为 Integer 列,`StockDailyBasic` 已含 `pb`)。

## 实现方法

在 `cal_valuation_factor` 内做局部增补,保持函数整体流程(交易日循环、取数、倒数变换、落库)不变,仅扩展「归一化(3.3)」与「合成(3.4)」两段,并同步更新 docstring。

### 关键决策与理由

1. **分量计算对齐历史**:`pb_ind_score = -val_df.groupby("industry")["pb_inv"].transform(lambda s: rank_to_score(s))`。沿用此前 `pb` 的行业内写法,保证语义一致(行业内高 PB→高分);`groupby("industry")` 依赖 `val_df["industry"]`(已在 3.1 后由 `stock_info` 映射填充)。
2. **缺失自适应合成**:`Wpb_ind = val_df["pb_ind_score"].notna().astype(float) * 2`,并入 `numerator` 与 `den`,避免该分量缺失时污染合成值;分母为 0 时置 NaN,由下游 `out_df[out_df["valuation"].notna()]` 自然剔除。
3. **值域与落库不变**:`mult_score`、`dv_ttm_score`、`pb_ind_score` 均为 `[-100,100]`,加权后 `valuation` 自然落回同区间,继续沿用现有 `np.floor` 取整 + `astype(int)` 落库,无需改动 3.5 之后逻辑。
4. **性能**:`groupby(...).transform(rank_to_score)` 为向量化组内操作,与现有截面计算同量级,无新增热点;循环外无额外取数。

### 实现注意事项

- 仅新增分量,**不删除**上一轮已落地的 trimmed-mean(`mult_score` / `Wm`)与独立 `dv_ttm`(权重 4)逻辑。
- `pb` 现在以两种身份参与(全市场价值 + 行业内相对溢价),计划中如实实现并在 docstring 明确标注,避免后续误解。
- 复用原 `np.errstate(divide="ignore", invalid="ignore")` 包裹除法,避免 NaN/0 告警。
- docstring 增补一步,说明新增行业内 PB 相对维度及其权重 2、方向。

## 关键代码结构(核心片段)

```python
# 3.3 归一化(新增行业内 PB 相对分量)
val_df["pb_ind_score"] = -val_df.groupby("industry")["pb_inv"].transform(
    lambda s: rank_to_score(s)
)  # 行业内排名后反向:高 PB -> 高分

# 3.4 合成(缺失自适应并入权重 2)
Wpb_ind = val_df["pb_ind_score"].notna().astype(float) * 2
numerator = (
    val_df["mult_score"].fillna(0) * Wm
    + val_df["dv_ttm_score"].fillna(0) * Wdv
    + val_df["pb_ind_score"].fillna(0) * Wpb_ind
)
den = Wm + Wdv + Wpb_ind
with np.errstate(divide="ignore", invalid="ignore"):
    val_df["valuation"] = np.where(den > 0, numerator / den, np.nan)
```
