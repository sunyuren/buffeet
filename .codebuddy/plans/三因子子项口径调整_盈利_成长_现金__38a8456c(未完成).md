## 用户需求

按指定口径调整 `src/factor.py` 中盈利/成长/现金三个复合因子的子项权重与归一化方式，并对"是否排除未正式上市股票报表"给出分析结论。

## 核心需求

1. **盈利因子 `cal_profit_factor`**

- R1 `roe_yearly`：权重 2 → 1（线性映射 `np.clip(roe_yearly*4, -100, 100)` 保持不变）。
- R4 `netprofit_margin`：由全市场 `rank_to_score` 改为**行业内** `rank_to_score(alpha=0.05)`，权重 1 → 0.5。
- R5 `ap_to_ar`：权重 1 → 0.5（行业内 rank 逻辑与金融置 0 不变）。
- R6 `equity`：由行业内 `rank_to_score` 改为**先 log10 平移、后行业内 `robust_z_to_score(alpha=0.05)`**，权重保持 1。

2. **成长因子 `cal_growth_factor`**

- R4 `total_revenue`：由行业内 `rank_to_score` 改为**先 log10 平移、后行业内 `robust_z_to_score(alpha=0.05)`**，权重保持 1。

3. **现金因子 `cal_cash_factor`**

- R4 `n_cashflow_act`（经营现金流净额）：由行业内 `robust_z_to_score` 改为**先 log10 平移、后行业内 `robust_z_to_score(alpha=0.05)`**，权重保持 1。

4. 同步更新三处函数 docstring 与 `weights` 行内注释。
5. 验证步骤仅校验无 lint 错误，**不重跑**因子计算。

## 已确认口径（此前澄清，无需再问）

- 盈利 R4「行业内比较」= 行业内 `rank_to_score`（与 R3/R5 口径一致，alpha=0.05）。
- 三个 log10 子项遇 ≤0 值 = 平移避免 inf：`log10(x - x.min() + 1)`（min 取全截面、skipna），最小值映射为 0，保留单调性。

## 上市前报表排除 —— 已分析确认，无需改动截面逻辑

- 三因子取财务底数后均执行：`fina_df = fina_df[fina_df["ts_code"].isin(stock_info)]`（仅保留官方股票清单内股票）；以及 `keep = ld.isna() | (end_date.astype(str) >= ld.astype(str))`（剔除报告期 `end_date` 早于上市日 `list_date` 的"上市前财报"）。
- 位置确认：盈利 1115-1122、成长 1312-1319、现金 1475-1482（fina_df）与 1501-1508（cf_df，即 R4 `n_cashflow_act`）。
- 结论：未正式上市（上市前）股票的报表已被有效排除，截面计算逻辑无需调整。残留边界（本轮不改）：`list_date` 缺失的股票保留全部报表。

## 技术栈

- 语言/运行时：Python 3（Buffett 虚拟环境），复用现有 `pandas` + `numpy`，不引入新依赖。
- 修改范围：仅 `src/factor.py`，不改 `database.py`、不改 schema、不影响其他因子（size/valuation/volility/reverse）。

## 实现方案

- 权重类改动（盈利 R1/R4/R5）只改 `weights` 字典值，合成逻辑"缺项按有效权重归一"不变。
- 归一化类改动（盈利 R4）将 `rank_to_score(section[col])` 替换为 `section.groupby("industry")[col].transform(lambda s: rank_to_score(s, alpha=0.05))`。
- log10 平移（盈利 R6 / 成长 R4 / 现金 R4）统一实现：先算 `shift = x - x.min()`（全截面、skipna），用 `np.errstate(divide="ignore", invalid="ignore")` 包裹 `np.log10(shift + 1)`，NaN 自然传播；再 `groupby("industry")` 内 `robust_z_to_score(alpha=0.05)`。与文件内既有 log10 写法（266-268、1336-1338 行）保持一致。
- 盈利 R6 在现有 `equity` 列（`total_assets*(1-debt_to_assets/100)`，非正值/缺失已置 NaN）之后追加 `equity_log` 中间列；成长 R4 / 现金 R4 在 `groupby.transform` 内直接完成平移+log+robust_z。

## 实现注意

- log10 平移的 min 必须在 `groupby` 外先按全截面计算，避免组内各自平移导致跨组不可比。
- 现金因子 `weights` 的键是 `r1_score`~`r4_score`（与盈利/成长的字段名键不同），本次现金仅改 R4 计算逻辑、不动 weights。
- 仅替换"子项归一化"环节，取数（含已确认的上市前报表排除）与落库链路不动，改动影响面最小。
