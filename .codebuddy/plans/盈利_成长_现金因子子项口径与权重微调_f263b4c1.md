## 用户需求

调整三个因子的指定子项口径与权重，使盈利因子更侧重质量与规模、成长/现金因子改用对数尺度降低右偏影响。

## 核心功能

- 盈利因子 `cal_profit_factor`：
- R1 roe_yearly 权重 2 → 1（归一化方式不变：`clip(4*x, -100, 100)`）。
- R4 netprofit_margin 由「全市场 rank_to_score」改为「行业内 rank_to_score(alpha=0.05)」，权重 1 → 0.5。
- R5 ap_to_ar 权重 1 → 0.5（归一化方式不变：行业内 rank_to_score，金融行业置 0）。
- R6 equity（净资产）先取对数再行业内 robust_z_to_score，权重保持 1。
- 成长因子 `cal_growth_factor`：R4 total_revenue 先取对数再行业内 robust_z_to_score，权重保持 1。
- 现金因子 `cal_cash_factor`：R4 n_cashflow_act（经营现金流净额）先取对数再行业内 robust_z_to_score，权重保持 1。
- 三个 log10 子项对 ≤0 值采用整体平移 `log10(x - x.min() + 1.0)`，避免 inf 且保留单调性。
- 全部落库逻辑、值域 [-100,100]、缺项有效权重归一均沿用现有实现，不改动表结构。

## 技术栈

- Python 3 + pandas + numpy（沿用工程，无新增依赖）
- 复用既有辅助函数：`rank_to_score`（factor.py:30）、`robust_z_to_score`（factor.py:67）
- 数据源：stock_fina_indicator（total_assets / debt_to_assets / total_revenue）、stock_cashflow（n_cashflow_act），均已在对应因子中读取

## 实现方案

### 总体策略

仅修改 `src/factor.py` 的三个因子函数。所有改动都落在「权重字典」「单子项归一化表达式」「行内注释/docstring」三处，合成逻辑（numerator/denom 按 weights 字典循环、缺项有效权重归一）完全复用，权重变动自动生效，无需改动合成与落库代码。

### 关键技术决策

1. **盈利 R4 用行业内 rank_to_score 而非 robust_z**：用户明确确认 R4「行业内比较」与现有 R3/R5 口径一致（行业内 rank_to_score, alpha=0.05），仅把原先的全市场 rank 改为组内 transform，最小侵入。
2. **log10 整体平移避免 inf**：`equity` 已保证 >0，但 `total_revenue` 可为 0、`n_cashflow_act` 可为负，直接用 `np.log10` 会产生 -inf/NaN。统一用 `logval = np.log10(x - x.min() + 1.0)`（x.min() 自动跳过 NaN），使最小观测映射到 1，全部为正、保序、无 inf。先算 logval 再 `groupby("industry")[logval].transform(robust_z_to_score, alpha=0.05)`。
3. **R6 equity 计算链**：保留现有推导 `equity = total_assets*(1 - debt_to_assets/100)` 与 `>0` 过滤，在其后追加 `equity_log` 列并改用 robust_z；与 R3/R5 的 rank 口径区分，符合用户对 R6 指定 robust_z 的指令。
4. **权重和变化**：盈利权重和由 7 变为 5（1+1+1+0.5+0.5+1），因合成按有效权重归一，无需整数约束，factor 列值域与取整逻辑不变。

### 性能与可靠性

- 改动均为列级向量运算（transform/向量化），与现有 O(截面股票数) 同量级，无新增瓶颈。
- log10 平移产生 NaN 的行在 robust_z_to_score 中保持 NaN，经有效权重归一自动剔除，不会导致除零（denom>0 判定已存在）。
- 不引入回归或新依赖，控制爆炸半径；三个因子改动相互独立，便于逐步验证。

## 实现注意事项

- 仅改 `src/factor.py`，不触碰 database / data_fetch / analyze_factor_ic。
- 平移公式统一：`np.log10(x - x.min() + 1.0)`，x 为该截面列 Series。
- 金融降级沿用：R5 ap_to_ar 金融置 0（本次仅权重变动）；R6 净资产对金融不置 0。
- 同步更新三因子函数 docstring 与行内注释，反映新权重、R4 行业内口径、R6/R4 的 log10 口径。

# 统一对数平移（盈利 R6 / 成长 R4 / 现金 R4 复用同一模式）
section["equity_log"]        = np.log10(section["equity"]        - section["equity"].min()        + 1.0)
section["total_revenue_log"] = np.log10(section["total_revenue"] - section["total_revenue"].min() + 1.0)
section["n_cashflow_act_log"]= np.log10(section["n_cashflow_act"]- section["n_cashflow_act"].min()+ 1.0)

section["r6_score"] = section.groupby("industry")["equity_log"].transform(
    lambda s: robust_z_to_score(s, alpha=0.05))
section["r4_score"] = section.groupby("industry")["total_revenue_log"].transform(
    lambda s: robust_z_to_score(s, alpha=0.05))   # 成长
section["r4_score"] = section.groupby("industry")["n_cashflow_act_log"].transform(
    lambda s: robust_z_to_score(s, alpha=0.05))   # 现金

# 盈利 R4 行业内比较（权重 0.5）
section["r4_score"] = section.groupby("industry")["netprofit_margin"].transform(
    lambda s: rank_to_score(s, alpha=0.05))
