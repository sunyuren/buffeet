## 产品概述

调整盈利因子（`cal_profit_factor`）第 6 个子项 R6 的底层指标：由原来的"净资产 equity"改为"总资产 total_assets"。

## 核心改动

- R6 不再用 `total_assets*(1-debt_to_assets/100)` 推导净资产，而是直接对每只股票的 `total_assets` 做标准化打分（作为规模优势代理，权重仍为 1）。
- 保持原有处理管线不变：全截面 log10 平移消除量纲 → 行业内 `robust_z_to_score(alpha=0.05)`。
- 有效性口径：仅当 `total_assets` 非空且大于 0 时纳入（非正值/缺失置 NaN，避免 log10 非正与 inf）。
- 因不再依赖负债率，`debt_to_assets` 在盈利因子中不再取数。
- 不影响其他因子与输出字段结构（`profit` 仍为 int 落库）。

## 技术栈

沿用项目现有栈：Python + pandas + numpy，单文件 `src/factor.py`，改动集中在 `cal_profit_factor`。

## 实现方案

高层面：把 R6 的"底层变量"由派生列 `equity` 换成原始列 `total_assets`，其余标准化/合成逻辑保持不变。

### 修改点（均在 `src/factor.py` 的 `cal_profit_factor` 内）

1. **R6 计算块**（当前 `# ---- 4.5b R6 净资产 ...` 段）：删除 equity 推导与 `equity_log`，改为直接对 `total_assets` 做 log10 平移 + 行业内 robust_z。目标代码：

```python
        # ---- 4.5b R6 总资产（先 log10 平移，再行业内 robust_z_to_score，权重 1）----
        # 有效性口径：total_assets 缺失或 <=0 的行置 NaN（避免 log10 非正与 inf）。
        section["total_assets"] = section["total_assets"].where(
            section["total_assets"].notna() & (section["total_assets"] > 0)
        )
        # 全截面 log10 平移（min 取全截面，组内各自平移会导致跨组不可比）：
        # total_assets_log = log10(total_assets - total_assets.min() + 1)，最小值映射为 0，无 inf。
        ta_log = section["total_assets"].sub(section["total_assets"].min()).add(1.0)
        with np.errstate(divide="ignore", invalid="ignore"):
            ta_log = np.where(section["total_assets"].notna(), np.log10(ta_log), np.nan)
        section["total_assets_log"] = ta_log
        section["r6_score"] = section.groupby("industry")["total_assets_log"].transform(
            lambda s: robust_z_to_score(s, alpha=0.05)
        )
```

2. **键名一致性（关键，否则 KeyError）**：`weights` 中 `"equity": 1` 改名为 `"total_assets": 1`；`score_cols` 中 `"r6_score": "equity"` 改为 `"r6_score": "total_assets"`（合成循环 `w = weights[base]` 依赖两处键一致）。
3. **取数字段** `fina_fields`：移除 `"debt_to_assets"`（盈利因子内除原 R6 外无其他引用，已核实；`moat` 仅是无关占位函数）。保留 `"total_assets"`。
4. **文档/注释同步**：docstring 的 R6 描述（"净资产 equity：由 total_assets*(1-debt_to_assets/100) 推导 ..."）改为"总资产 total_assets：全截面 log10 平移后行业内 robust_z_to_score(alpha=0.05)，权重 1（奖励规模优势）"；合成公式 `1*equity `改为 `1*total_assets`；`weights` 内 `total_assets` 行注释同步；R6 段内行内注释同步。

## 关键决策与权衡

- **仅换底层变量、不改管线**：最小改动、风险最低，保持与成长 R4（`tr_log`）、现金 R4（`cf_log`）一致的 log10 平移写法（`x.sub(x.min()).add(1.0)` + `np.where(x.notna(), np.log10(...), np.nan)`，`np.errstate` 包裹），符合文件既有惯例（DRY）。
- **权重和不变**：仍为 5（1+1+1+0.5+0.5+1），缺项按有效权重归一逻辑不变，对下游 `profit` 数值口径影响最小。
- **移除 debt_to_assets**：避免无谓取数；若未来 R6 需回归净资产口径，可从该列重新启用。

## 性能与可靠性

- 计算量与原来同阶（一次列级 log10 + 一次行业内 groupby robust_z），无新增复杂度。
- 与刚完成的"退化分支保持 NaN"修复协同：当 `total_assets` 在当日截面整列为空时，`robust_z_to_score` 会保持缺失为 NaN（不再全市场赋 0），从而无数据的股票被 `out_df[...notna()]` 正确过滤。
