3.3 归一化(pb 行业组内 ×-1、ps 用 rank_to_score,移除 `pb_ind_score`):

```
        # ---- 3.3 归一化 ----
        # dv_ttm / pe_ttm：全市场稳健标准化（robust_z_to_score，不反向）
        val_df["dv_ttm_score"] = robust_z_to_score(val_df["dv_ttm"].astype(float), alpha=0.05)
        val_df["pe_ttm_score"] = robust_z_to_score(val_df["pe_ttm_inv"], alpha=0.05)
        # ps_ttm：全市场排名百分比归一化（rank_to_score，不反向）
        val_df["ps_ttm_score"] = rank_to_score(val_df["ps_ttm_inv"], alpha=0.05)
        # pb：按行业分组、行业内排名百分比归一化（rank_to_score），再乘 -1 反向
        val_df["pb_score"] = -val_df.groupby("industry")["pb_inv"].transform(
            lambda s: rank_to_score(s)
        )
```

3.4 加权合成(固定权重循环,移除 `Wm`/`Wdv`/`Wpb_ind`/`mult_score`):

```
        # ---- 3.4 加权合成（缺项按有效权重归一）----
        score_cols = {
            "dv_ttm_score": "dv_ttm",
            "pe_ttm_score": "pe_ttm",
            "pb_score": "pb",
            "ps_ttm_score": "ps_ttm",
        }
        numerator = pd.Series(0.0, index=val_df.index)
        denom = pd.Series(0.0, index=val_df.index)
        for sc, base in score_cols.items():
            w = weights[base]
            valid = val_df[sc].notna()
            numerator = numerator + np.where(valid, val_df[sc] * w, 0.0)
            denom = denom + np.where(valid, w, 0.0)

        with np.errstate(divide="ignore", invalid="ignore"):
            valuation_raw = np.where(denom > 0, numerator / denom, np.nan)
        val_df["valuation"] = valuation_raw
```
