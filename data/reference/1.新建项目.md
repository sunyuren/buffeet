## 二、巴菲特风格——基本面因子建议

基于您的项目名 `buffeet`，建议重点构建以下因子体系：

### 📊 价值因子（Valuation）
```
低 PE（市盈率）+ 低 PB（市净率）+ 低 PS（市销率）
→ 筛选被低估的股票
```

### 📈 质量因子（Quality）—— 巴菲特最核心的选股逻辑
```
高 ROE（净资产收益率）持续 > 15%
高净利润增长率（profit_yoy）> 10%
高毛利率（grossprofit_margin）> 30%
低资产负债率（debt_to_assets）< 50%
```

### 💰 现金流因子（Cash Flow）
```
经营性现金流 / 净利润 > 1  （盈利质量高）
自由现金流为正
```

### 🏆 护城河因子（Moat）
```
ROE 连续3年稳定 > 15%  （盈利能力持续）
营收复合增长率 > 10%     （成长性）
```
